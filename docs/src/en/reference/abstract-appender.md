# AbstractAppender

AbstractAppender is the base class for all appenders, and all listed methods can be invoked in other appenders.

## `constructor(name, level, type)`

- `name` string - Appender name
- `level` Level - Appender log level
- `type` AppenderTypeEnum - Appender type

When creating a custom appender, the subclass constructor should call `super(name, level, type)`.

## `getName()`

Obtain the Appender name

## `getCurrentHistory()`

Obtain all logs generated by the current session (history must be enabled via `setEnableHistory(true)`)

## `setLayout(layout)` <Badge type="tip" text="1.4.0 +" />

- `layout` T extends AbstractLayout - Log layout

Set the log layout for the Appender

## `makeMessage(level, tag, time, count, message, tempContext)`

- `level` Level - Log level
- `tag` string - Log tag
- `time` number - Log trigger time
- `count` number - Log sequence number
- `message` string | ArrayBuffer - Log message
- `tempContext` TemporaryLoggerContext - Log temporary context

Uses the current Appender layout to format log parameters into the final output content

## `onLog(level, tag, time, count, message, tempContext)`

- `level` Level - Log level
- `tag` string - Log tag
- `time` number - Log trigger time
- `count` number - The count-th log printed by the bound Logger
- `message` string - Log message
- `tempContext` TemporaryLoggerContext - Log temporary context

Called by the bound Logger when a log is recorded

## `getType()`

Gets the current Appender type

## `getId()`

Gets the current Appender id

## `setId(id)`

- `id` number - Id to set

Sets the current Appender id

## `setLevel(level)`

- `level` Level - Log level to set

Resets the current Appender log level

## `addHistory(...message): this`

- `message` string[] - Logs to add to history

Adds logs to the current Appender history. Only works when history is enabled.

## `clearHistory(): this`

Clears the current Appender history

## `setEnableHistory(enable): this` <Badge type="tip" text="1.6 +" />

- `enable` boolean - Whether to enable history

Enables or disables Appender history.

## `setMaximumHistoryCount(count): this` <Badge type="tip" text="1.6 +" />

- `count` number - Maximum history count

Sets the maximum number of history records. When exceeded, the oldest record is removed automatically.

## `onTerminate()`

Terminates the output of the current Appender and cleans up memory garbage
